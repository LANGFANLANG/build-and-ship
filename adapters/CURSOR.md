# Cursor Adapter for Build-and-Ship

Copy this content into Cursor project rules or adapt it for `.cursorrules`.

For coding tasks, use Build-and-Ship:

1. Understand the user request.
2. Draft and confirm PRD for non-trivial work.
3. Inspect existing project before changes.
4. Detect environment tools and missing runtimes.
5. Recommend and confirm tech stack for new projects or major modules.
6. Design only what the confirmed PRD needs.
7. Plan the smallest runnable MVP first.
8. Implement in small verifiable steps.
9. Run tests, build, app startup, and smoke verification.
10. Deliver with exact startup command, URL, verified features, unverified items, and next step.

For AI coding beginners, turn a single idea into:

```text
PRD draft
Recommended stack
Project structure
MVP phases
Confirmation questions
```

Avoid overbuilding. Prefer local runnable apps before backend, database, Docker, CI, and deployment unless required.
